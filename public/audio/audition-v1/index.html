토끼 돌진 효과음 시안

버튼을 눌러 비교해 보세요. ‘돌진 + 명중’은 선택 후 0.16초에 타격음이 나오는 0.48초 연출입니다.

자동 재생 없이 버튼을 누르면 재생됩니다.

A · 단단한 팍

짧은 충격음과 낮은 몸통 울림. 타격 시작을 강조한 후보.

B · 젤리 뽁

높낮이가 내려가는 팝과 작은 젤리 방울. 말랑한 몬스터에 맞춘 후보.

C · 팍 + 젤리 파열

단단한 충격 뒤에 젤리가 터지는 조합. 현재 돌격에 우선 적용해 볼 후보.

오답 · 휙 → 털썩

빗나가는 바람과 배로 착지하는 짧은 소리.

직접 합성한 비교용 시안입니다. 게임에는 아직 연결하지 않았습니다. 트릭스터 원본 녹음을 사용하지 않았습니다.
