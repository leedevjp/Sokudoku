# 보물상자 도트 시트

상자와 캐릭터를 분리한 아트/연출 시안입니다. `/pets/treasure-preview.html`에서 등급별로 열기를 재생하고 각 시트를 따로 확인할 수 있습니다. 실제 학습 보상·확률·인벤토리·재화 저장은 구현하지 않았습니다.

- `public/treasure/chests-pixel-v1.png`: 8열×3행, 커먼(나무/철), 레어(남색/은/청록 보석), 유니크(자주/금/날개 장식). 각 행은 닫힘부터 열린 상태까지 8프레임.
- `public/treasure/mage-opening-pixel-v1.png`: 4열×2행, 발견 → 기울임 → 손 뻗기 → 잠금 풀기 → 들어 올리기 → 열기 완료 → 놀람 → 기쁨. 캐릭터에는 상자를 포함하지 않습니다.
- 각 JSON의 `frames`는 원본의 실제 픽셀 좌표입니다. 생성 이미지 크기가 정수 셀로 나뉜다고 가정하지 않습니다.

이전 토끼 시안의 작은 픽셀 군집과 얇은 윤곽을 스타일 기준으로 삼고, 마법사의 흰 머리·남색/금색 모자·아이보리 의상을 단순화한 신규 생성 이미지입니다. 원래 게임의 프레임을 새 상자에 복사한 것이 아닙니다. 기존 캐릭터/전투 이미지는 덮어쓰지 않았습니다.

원본 생성 PNG는 네이티브 64px 팔레트 시트가 아닙니다. 미리보기는 각 프레임을 64×64 논리 셀로 최근접 샘플링하고 `image-rendering: pixelated`로 확대해 작은 게임 크기의 외관을 확인합니다. 완전히 고정된 팔레트·이진 알파를 보장하는 수작업 시트로 표현하지 않습니다. 실제 게임 통합 전에는 손과 뚜껑의 접점·타이밍·발 위치를 최종 화면 배율에서 다시 맞춰야 합니다.

생성은 기본 이미지 생성 도구로 진행했으며 상자의 배경 정리, 캐릭터의 웅크림/손 뻗기 및 불필요한 물음표 제거를 별도 수정했습니다. 열기 미리보기는 공통 바닥 위치와 서로 다른 프레임 진행을 조합하고, reduced motion에서는 마지막 상태만 표시합니다.
